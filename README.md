# CMA in Action

المسار الرئيسي: **محاسبة التكاليف الصناعية في SAP S/4HANA**

تعلّم كيف تُحسب تكلفة الإنتاج في SAP، وتتبع الأرقام من أرض المصنع إلى تقارير التكاليف والانحرافات

**افتح المنصة:** https://nabig-abdalla.github.io/sap-cost-lab/

- 11 درساً تتبع دورة التكلفة: البيانات، التخطيط والتكلفة المعيارية، تنفيذ الإنتاج، الرقابة والإقفال
- كل معلومة فنية أو محاسبية تحمل رقم مرجعها الرسمي من SAP Learning أو SAP Help Portal، وما تعذّر توثيقه لا يُنشر
- الأرقام التدريبية من أمثلة SAP الموثقة أو من بيانات زوّدها معد المنصة
- قاموس مصطلحات بمراجعه، ودليل شركات في المنطقة تستخدم SAP بمصادر من SAP News Center أو إعلانات الشركات
- قريبًا: شرح عملي بالفيديو على برنامج SAP

تطوير **نابغ عبدالله محمد**، رئيس حسابات ومحاسب تكاليف صناعية

محتوى تعليمي مستقل، غير تابع لـ SAP أو IMA
