# منصة التطبيق العملي للتكاليف الصناعية وفق SAP وCMA

مسار عربي مجاني من 8 دروس تفاعلية في تكاليف مصانع حقن البلاستيك على SAP S/4HANA، مربوط بمنهج CMA Part 1

**افتح المنصة:** https://nabig-abdalla.github.io/sap-cost-lab/

- شرح بالعربية مع المصطلح الإنجليزي ورمز المعاملة
- محاكاة لشاشات SAP بأسماء حقولها
- تمارين تُصحَّح فوراً مع تحديد نوع الخطأ
- لوحة تقدم، وسجل أخطاء، وتصدير Excel

إعداد **نابغ عبدالله**، خبير التكاليف الصناعية، وفق خبرة عملية في مجال التكاليف الصناعية

محتوى تعليمي مستقل، غير تابع لـ SAP أو IMA
