# محاسبة التكاليف الصناعية في SAP S/4HANA

منصة عربية عملية لطلاب المحاسبة ودارسي CMA ومحاسبي التكاليف: فهم دورة التكلفة الصناعية، وتطبيقها في SAP، وشرح نتائجها بالمصطلحات الإنجليزية المستخدمة في العمل والتقارير والمقابلات

**افتح المنصة:** https://nabig-abdalla.github.io/sap-cost-lab/

- 11 درساً في 4 وحدات: البيانات والأساس، التخطيط والتكلفة المعيارية، تنفيذ الإنتاج، الرقابة والقرار
- حالات من الصناعات الغذائية والكيميائية والمعدنية والبلاستيكية وتجميع المعدات، بالتصنيع المنفصل وبالعمليات وPEO
- كل درس: موقف صناعي، مفهوم محاسبي، تطبيق في SAP، تمرين يُصحَّح فوراً، تفسير النتيجة بجملة مهنية بالإنجليزية
- قاموس مصطلحات عربي إنجليزي، وربط بمنهج CMA Part 1، ولوحة تقدم وتصدير Excel

إعداد **نابغ عبدالله**، خبير التكاليف الصناعية، وفق خبرة عملية في مجال التكاليف الصناعية

محتوى تعليمي مستقل، غير تابع لـ SAP أو IMA
